A responsive Myntra homepage clone built using HTML and CSS.
This project recreates the look and feel of the popular fashion e-commerce website Myntra, focusing on layout design, styling, and responsiveness.

It is a beginner-friendly frontend project created to practice HTML structure, CSS styling, Flexbox, and responsive design concepts.

🚀 Features

Modern Myntra inspired UI

Responsive layout

Navigation bar with categories

Search bar UI

Banner section

Product category sections

Footer with useful links

Clean and structured code

🛠️ Technologies Used

HTML5 – Page structure

CSS3 – Styling and layout

Flexbox – Responsive layout design

Google Fonts / Icons (optional)
